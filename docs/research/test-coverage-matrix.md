# Principal-client universal-gate coverage matrix

Status: executable-evidence inventory, 2026-08-23. This is a coverage map, not an accepted
semantic declaration. It covers only the internal modules assigned to the test-hardening lane by
[`test-hardening-brief.md`](../architecture/test-hardening-brief.md), item 2.

## How to read the matrix

Each evidence cell names the exact `test file › test name` that exercises the operation. `n/a`
means the gate cannot arise for that operation's shape (for example, a total pure predicate has no
blocked state or finalizer); it is not evidence and is not counted as a gap. A test in this table
establishes only its tier under `test/AGENTS.md`.

The universal gates are: exact success; every expected typed failure; interruption while blocked;
finalization after success, failure, and interruption; producer/consumer saturation; and secret
redaction. Constructors, service tags, exported types, and constant values are listed only when
they perform work; passive declarations such as `Connector`, `NatsTransport`, `defaultPolicy`, and
`layerNodeConnector` do not create a separate operation row.

close the decision gaps recorded in `TO_FIX.md`: Core overflow ordering is not yet ratified, and

the implementation's current executable evidence without promoting either choice into a new
semantic promise.
